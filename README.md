# PARALLAX

A very small experimental physics game for PC.

> A tiny prototype about testing physics and messing with objects.

## About

**PARALLAX** is an early prototype for a first-person physics sandbox.

Right now, the game is extremely small. It consists of a single test area and a few basic interactions.

There is no story, progression, multiplayer, or large world yet.

The current goal is simply to get the basic physics and player interaction working.

## Current Features

Currently, you can:

* Walk around
* Look around
* Jump
* Pick up objects
* Throw objects
* Push objects
* Interact with basic physics objects

That's currently the entire game.

## Current Environment

There is **one small test room**.

It contains:

* A floor
* A few walls
* Several simple objects
* A basic testing area

There are currently no other maps.
